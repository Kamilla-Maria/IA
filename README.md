# Hello Kitty SaaS & Game Master 🎀

Aplicação SaaS interativa com Inteligência Artificial Generativa (Google Gemini), banco de dados MongoDB e autenticação via JWT.

## 🚀 Tecnologias Utilizadas
- **Back-end:** Node.js, Express.js
- **Banco de Dados:** MongoDB Atlas com Mongoose
- **Autenticação:** JSON Web Token (JWT) e Bcrypt.js
- **IA e Multimodal:** Google Generative AI SDK (`gemini-1.5-flash`)
- **Upload de Arquivos:** Cloudinary + Multer
- **Deploy:** Vercel
